# Mettu University

## Overview

- **Official website:** [https://www.meu.edu.et/](https://www.meu.edu.et/)
- **Institution type:** Not confirmed
- **Main location:** Mettu, Illubabor Zone, Oromia Region, Ethiopia. The official site self-identifies as "Mattu University" (Yuunivarsiitii Mattuu / መቱ ዩኒቨርሲቲ) — an alternate transliteration of the same name listed in the project's source list as "Mettu University."
- **Data status:** Needs review

The university operates a main campus and a separate Bedele campus with its own colleges.
